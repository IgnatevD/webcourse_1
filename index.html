Спочатку встанови інструменти, у яких створюватимеш і зберігатимеш свій проєкт.

1. Встановлення VS Code

Visual Studio Code — безкоштовний редактор для веброзробки.

  1. Перейди на code.visualstudio.com.
  2. Завантаж версію для Windows, macOS або Linux.
  3. Встанови програму зі стандартними налаштуваннями.

2. Встановлення Git

Git — система контролю версій. Вона допомагає зберігати історію змін і синхронізувати код із GitHub.

  1. Відкрий git-scm.com/downloads.
  2. Завантаж та встанови Git.
  3. Відкрий термінал VS Code і перевір встановлення:
git --version

✓ Якщо відображається номер версії, Git встановлено.

3. Налаштування Git

Виконай ці команди один раз, підставивши власне ім’я та email. Саме ці дані відображатимуться в комітах.

git config --global user.name "Твоє ім’я"
git config --global user.email "твоя@пошта.com"

4. Створи облікові записи

  • GitHub — сервіс для зберігання коду в репозиторіях.
  • Netlify — сервіс для публікації сайту. Реєстрація через GitHub спростить підключення.

Репозиторій — це місце, де зберігатиметься історія твого проєкту. Надалі Netlify зможе автоматично публікувати зміни з GitHub.

1. Створи репозиторій на GitHub

  1. Увійди на GitHub.
  2. Натисни “+” → “New repository”.
  3. Вкажи назву, наприклад webcourse.
  4. Обери Public, якщо хочеш зробити код відкритим.
  5. Натисни Create repository.

2. Склонуй репозиторій у VS Code

  1. Створи або вибери папку, у якій зберігатимеш проєкти.
  2. Відкрий термінал у VS Code: Ctrl + ` або меню View → Terminal.
  3. Скопіюй адресу свого репозиторію на GitHub і виконай команду:
git clone https://github.com/ТВІЙ-ЛОГІН/webcourse.git

Заміни ТВІЙ-ЛОГІН на свій логін, а назву репозиторію — на фактичну, якщо вона інша.

HTML відповідає за структуру, CSS — за зовнішній вигляд, а JavaScript — за взаємодію з користувачем.

1. Створи три файли проєкту

У папці проєкту створи такі файли:

webcourse/
├── index.html
├── style.css
└── script.js

2. Базова структура HTML — index.html

<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Мій перший сайт</title>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>
<body>
  <main>
    <h1>Всім привіт! 👋</h1>
    <p>Це мій перший сайт на HTML, CSS і JavaScript.</p>
    <button id="helloBtn" type="button">Натисни мене</button>
  </main>
</body>
</html>

3. Додай стилі — style.css

body {
  font-family: Arial, sans-serif;
  text-align: center;
  margin: 100px 20px 0;
  background-color: #f0f0f0;
}

h1 {
  color: #333;
}

button {
  background-color: #007bff;
  color: white;
  border: 0;
  padding: 10px 20px;
  border-radius: 8px;
  cursor: pointer;
}

button:hover {
  background-color: #0056b3;
}

4. Додай JavaScript — script.js

document
  .getElementById("helloBtn")
  .addEventListener("click", () => {
    alert("Вітаю! Ви створили свій перший сайт 🚀");
  });

5. Збережи зміни та надішли їх на GitHub

Після редагування файлів виконай у терміналі:

git add .
git commit -m "update site"
git push
  • git add . — додає всі зміни до підготовки коміту.
  • git commit — зберігає підготовлені зміни в локальній історії.
  • -m — задає коротке повідомлення коміту.
  • git push — надсилає коміти на GitHub.

Netlify може автоматично збирати й публікувати сайт після кожного оновлення репозиторію.

Крок 1. Підключи GitHub

  1. Перейди на Netlify та увійди через GitHub.
  2. Натисни Add new site → Import an existing project.
  3. Обери GitHub як джерело коду та надай потрібний доступ.

Крок 2. Вибери репозиторій

  1. Знайди свій репозиторій, наприклад webcourse.
  2. Для звичайного HTML/CSS/JS-проєкту залиш Build command порожнім.
  3. Якщо файли лежать у корені репозиторію, Publish directory — ..
  4. Натисни Deploy site.

✓ Після успішного деплою Netlify надасть адресу на кшталт назва-сайту.netlify.app.

  • Знайти помилку у фрагменті коду та пояснити її.
ГОТОВИЙ ПРОМТ

Створи повністю готовий сучасний адаптивний сайт (mobile-first), використовуючи чистий HTML5, CSS3 і JavaScript без фреймворків. Розмісти код у трьох файлах: index.html, style.css і script.js.

Кожна секція має містити заголовок, який розкриває вміст після натискання з плавною анімацією. Використай мінімалістичний дизайн, однорідний фон, м’які тіні, плавні переходи та ефект матового скла (glassmorphism) для карток. Передбач коректне відображення на смартфонах, планшетах і комп’ютерах. Для кольорів та інших повторюваних значень використовуй CSS-змінні.

Ось структура й контент сторінки: [додай власний контент]. Поверни повний код кожного файлу окремо та коротко поясни, як запустити сайт локально.

Поради для ефективної роботи з ChatGPT

  1. Формулюй завдання конкретно та додавай контекст.
  2. Проси пояснити рішення покроково або на прикладі.
  3. Надсилай фрагменти коду й текст помилки, якщо щось не працює.
  4. Спробуй запити: «Зроби код простішим», «Додай анімацію при наведенні», «Оптимізуй швидкість завантаження».

ШІ — помічник у навчанні, а не заміна власного розуміння коду. Перевіряй результат і тестуй його.

Публікація робить сайт доступним за посиланням, а індексація допомагає Google знайти його та потенційно показувати в пошуку.

1. Перевір доступність сайту

  1. Відкрий адресу, яку надав Netlify, наприклад https://webcourse.netlify.app.
  2. Переконайся, що сторінка відкривається без помилок.
  3. Скопіюй повну адресу сайту.

2. Створи ресурс у Google Search Console

  1. Перейди на Google Search Console.
  2. Натисни «Почати» та увійди в Google-акаунт.
  3. Обери тип ресурсу «Префікс URL» і введи адресу сайту з Netlify.

3. Підтверди право власності через HTML-тег

  1. У Search Console обери метод підтвердження «HTML tag».
  2. Скопіюй метатег, який надасть Google. Він матиме приблизно такий вигляд:
<meta name="google-site-verification" content="ТВІЙ_КОД" />
  1. Встав тег у секцію <head> файлу index.html.
  2. Збережи зміни та виконай git add ., git commit і git push.
  3. Дочекайся оновлення сайту на Netlify, повернись у Search Console та натисни «Verify».

4. Запроси індексацію

  1. Відкрий інструмент «Перевірка URL» (URL Inspection).
  2. Встав повну адресу опублікованої сторінки.
  3. Натисни «Запросити індексацію» (Request indexing).

Запит не гарантує індексацію та не має фіксованого строку виконання. Google сам вирішує, коли й чи додавати сторінку до результатів пошуку.

5. Додай sitemap.xml (необов’язково)

Створи у корені проєкту файл sitemap.xml та підстав свою реальну адресу сайту:

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="https://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://webcourse.netlify.app/</loc>
  </url>
</urlset>

Завантаж файл у GitHub, дочекайся деплою, а потім у Search Console відкрий розділ «Sitemaps» і надішли sitemap.xml.

✓ Готово! Ти пройшов шлях від локального проєкту до опублікованого сайту, доступного для сканування Google.
