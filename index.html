01

          

            
Етап 1 · 🛠️

            
Підготовка середовища

            
Інструменти й облікові записи, які знадобляться

          

        


        

          

            
            

              

                
VS Code (Visual Studio Code) — безкоштовний, легкий і зручний редактор для
                  веброзробки.

                
🔹 Як встановити

                
    
                  
  1. Перейди на code.visualstudio.com.
    2. 
                  
  2. Завантаж версію для своєї операційної системи (Windows, macOS або Linux).
    3. 
                  
  3. Встанови програму, залишаючи стандартні налаштування.
    4. 
                

              

            

          


          

            
            

              

                
Git — система контролю версій. Вона дозволяє зберігати зміни в коді, працювати з
                  репозиторіями на GitHub і публікувати сайт на Netlify.

                
🔹 Як встановити

                
    
                  
  1. Зайди на git-scm.com/downloads.
    2. 
                  
  2. Завантаж і встанови Git (натискай «Next» усюди за замовчуванням).
    3. 
                  
  3. Відкрий термінал VS Code або Command Prompt і введи:
    4. 
                

                
git --version

                
✅ Якщо бачиш номер версії — Git встановлено успішно.

              

            

          


          

            
            

              

                
Перед першою роботою з Git введи свої дані в терміналі (лише один раз):

                
git config --global user.name "Твоє ім’я"
git config --global user.email "твоя@пошта.com"

                
💡 Це потрібно, щоб коміти на GitHub підписувалися твоїм ім’ям.

              

            

          


          

            
            

              

                

                  

                    🐙
                    
GitHub

                    
Зареєструйся або увійди. Тут зберігатиметься твій сайт (репозиторій).

                  

                  

                    🌐
                    
Netlify

                    
Створи акаунт через GitHub — так простіше підключити сайт. Netlify сам підключиться до
                      репозиторію й опублікує сайт онлайн.

                  

                

              

            

          

        

      


      
      

        

          
02

          

            
Етап 2 · 🧱

            
Git-репозиторій і GitHub

            
🎯 Зберегти проєкт у хмарі, щоб його бачили інші й міг підключити Netlify

          

        


        

          

            
            

              

                
    
                  
  1. Зайди на github.com.
    2. 
                  
  2. У верхньому правому куті натисни «+» → New repository.
    3. 
                  
  3. Введи назву, наприклад: webcourse.
    4. 
                  
  4. Обери Public, щоб сайт був доступний усім.
    5. 
                  
  5. Натисни Create repository.
    6. 
                

                
GitHub створить порожнє сховище й покаже інструкції, як підключити його до локального проєкту.

              

            

          


          

            
            

              

                
    
                  
  1. Обери папку, де зберігатиметься проєкт, і відкрий її через File → Open Folder
                    (Файл → Відкрити папку).
    2. 
                  
  2. Увімкни термінал: Ctrl + ` або меню View →
                      Terminal.
    3. 
                  
  3. Склонуй свій репозиторій:
    4. 
                

                
git clone https://github.com/твій_логін/webcourse.git

              

            

          

        

      


      
      

        

          
03

          

            
Етап 3 · ⚙️

            
Створення сайту

            
HTML + CSS + JS + AI

          

        


        

          

            
            

              

                
У папці webcourse створи 3 файли:

                

                  
HTMLindex.htmlструктура
                  

                  
CSSstyle.cssвигляд

                  
JSscript.jsповедінка

                

              

            

          


          

            
            

              

                
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Мій перший сайт</title>
  <link rel="stylesheet" href="style.css" />
</head>
<body>
  <h1>Всім привіт! 👋</h1>
  <p>Це мій перший сайт на HTML, CSS і JavaScript.</p>
  <button id="helloBtn">Натисни мене</button>

  <script src="script.js"></script>
</body>
</html>

              

            

          


          

            
            

              

                
body {
  font-family: Arial, sans-serif;
  text-align: center;
  margin-top: 100px;
  background-color: #f0f0f0;
}

h1 {
  color: #333;
}

button {
  background-color: #007bff;
  color: white;
  border: none;
  padding: 10px 20px;
  border-radius: 8px;
  cursor: pointer;
}

button:hover {
  background-color: #0056b3;
}

              

            

          


          

            
            

              

                
document.getElementById("helloBtn").addEventListener("click", function () {
  alert("Вітаю! Ви створили свій перший сайт 🚀");
});

                

                  
Спробуй, як працює кнопка:

                  
                

              

            

          


          

            
            

              

                
Після кожної зміни коду введи в терміналі VS Code:

                
git add .
git commit -m "update site"
git push

                

                  

                    
git add

                    
додати файл або зміни до черги збереження

                  

                  

                    
.

                    
крапка — усі файли в поточній папці та підпапках

                  

                  

                    
git commit

                    
зберігає зміни в локальній історії

                  

                  

                    
-m

                    
message — повідомлення до коміту

                  

                  

                    
"update site"

                    
короткий опис того, що саме ти змінив

                  

                  

                    
git push

                    
надсилає ці зміни на GitHub

04

          

            
Етап 4 · 🚀

            
Публікація через Netlify

            
Сайт онлайн за кілька хвилин

          

        


        

          

            
            

              

                
    
                  
  1. Перейди на netlify.com.
    2. 
                  
  2. Натисни Log in → GitHub і увійди через свій акаунт.
    3. 
                  
  3. Після входу натисни Add new site → Import an existing project.
    4. 
                  
  4. Обери GitHub як джерело коду.
    5. 
                

              

            

          


          

            
            

              

                
    
                  
  1. У списку знайди репозиторій webcourse і натисни на нього.
    2. 
                  
  2. У полі Build settings нічого не змінюй — для HTML/CSS/JS це не потрібно.
    3. 
                  
  3. Натисни Deploy site.
    4. 
                

                

                  GitHub
                  
                  Netlify
                  
                  Онлайн 🌍
                

                
💫 Netlify опублікує сайт за кілька секунд, а після кожного
                  git push оновлюватиме його автоматично.

              

            

          

        

      


      
      

        

          
05

          

            
Етап 5 · 🤖

            
ШІ для власної ідеї сайту

            
ChatGPT та інші AI-інструменти як помічники

          

        


        

          

            
            

              

                

                  
🧱
                    
HTML-шаблони

                    
«Зроби адаптивну сторінку з меню та футером»

                  

                  
🎨
                    
CSS-стилі

                    
«Додай стиль як у сучасного сайту-портфоліо»

                  

                  
⚡
                    
JS-скрипти

                    
«Зроби кнопку, яка змінює колір фону»

                  

                

              

            

          


          

            
            

              

                
Скопіюй цей промт і додай у кінці свій контент:

                
Створи повністю готовий сучасний адаптивний сайт (mobile-first), використовуючи чистий HTML5, CSS3 і JavaScript (без фреймворків), у трьох основних файлах index.html, style.css, script.js.

У кожній секції має бути тема з назвою, яка розкривається при натисканні (плавне розгортання).

- принцип mobile-first, щоб сайт коректно виглядав на смартфонах, планшетах і комп’ютерах;
- мінімалістичний, чистий стиль (однотонний фон, м’які тіні, плавні переходи);
- використовуй константи для кольорів та інших стилів;
- плавні анімації для відкривання/закривання блоків;
- ефект матового прозорого скла (glassmorphism) для карток та секцій.

Використай цей контент для структури сторінки: [додай власний контент]

              

            

          


          

            
            

              

                
    
                  
  1. Пиши конкретно, чітко формулюй завдання.
    2. 
                  
  2. Проси «покроково» або «з прикладом».
    3. 
                  
  3. Надсилай фрагменти свого коду — ChatGPT пояснить, що не працює.
    4. 
                  
  4. Використовуй підказки:
    5. 
                

                

                  «Зроби цей код простішим»
                  «Додай анімацію при наведенні»
                  «Оптимізуй для швидкого завантаження»
                

                
💡 Штучний інтелект не замінює тебе, а допомагає писати код швидше й з
                  підказками.

              

            

          

        

      


      
      

        

          
06

          

            
Етап 6 · 🌍

            
Індексація в Google

            
Щоб сайт знаходили в пошуку

          

        


        

          

            
            

              

                
    
                  
  1. Відкрий свій сайт, наприклад: https://твій-сайт.netlify.app
    2. 
                  
  2. Переконайся, що сторінка відкривається без помилок.
    3. 
                  
  3. Скопіюй це посилання — воно знадобиться далі.
    4. 
                

              

            

          


          

            
            

              

                
    
                  
  1. Перейди на Google Search Console.
    2. 
                  
  2. Натисни «Почати» (Start now).
    3. 
                  
  3. Увійди під своїм акаунтом Google.
    4. 
                

              

            

          


          

            
            

              

                
    
                  
  1. Обери варіант «Префікс URL» (а не «Домен»).
    2. 
                  
  2. Введи адресу сайту з Netlify, наприклад: https://webcourse.netlify.app
    3. 
                  
  3. Натисни Далі (Continue).
    4. 
                

              

            

          


          

            
            

              

                
Google попросить підтвердити, що сайт належить тобі. Найпростіше — через HTML-тег:
                

                
    
                  
  1. Обери метод «HTML tag» і скопіюй код такого вигляду:
    2. 
                

                
<meta name="google-site-verification" content="твій_код_перевірки" />

                
    
                  
  1. Встав цей тег у розділ <head> файлу index.html:
    2. 
                

                
<head>
  <meta charset="UTF-8" />
  <meta name="google-site-verification" content="твій_код_перевірки" />
  <title>Мій сайт</title>
</head>

                
    
                  
  1. Збережи зміни, зроби коміт і push на GitHub, дочекайся оновлення на Netlify (1–2 хвилини).
    2. 
                  
  2. Повернись у Google Search Console і натисни «Verify» (Перевірити).
    3. 
                

              

            

          


          

            
            

              

                
    
                  
  1. Після підтвердження відкрий вкладку URL Inspection (Перевірка URL).
    2. 
                  
  2. Встав адресу свого сайту:
    3. 
                

                
https://webcourse.netlify.app/

                
    
                  
  1. Натисни Request Indexing (Запросити індексацію).
    2. 
                  
  2. Google поставить сайт у чергу на сканування — зазвичай це займає кілька днів.
    3. 
                

              

            

          


          

            
            

              

                
    
                  
  1. Створи файл sitemap.xml у корені сайту:
    2. 
                

                
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://webcourse.netlify.app/</loc>
    <priority>1.00</priority>
  </url>
</urlset>

                
    
                  
  1. Завантаж цей файл у репозиторій — Netlify оновить сайт.
    2. 
                  
  2. У Google Search Console відкрий розділ Sitemaps і додай: sitemap.xml
                  
    3.
